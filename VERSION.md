# Версии Pill Studio

Текущая версия приложения — **0.4.0**. Номер используется в интерфейсе,
установщике Windows и пакете macOS. Версия прошивки STM32 определяется
отдельно через Git при её сборке.

## Как выпустить новую версию

1. Измените `[package].version` в [studio/Cargo.toml](studio/Cargo.toml).
   Это источник номера для обоих скриптов упаковки. Для новой функции
   увеличьте минорную часть и обнулите последнюю, например `0.4.0 → 0.5.0`.
   Для исправления увеличьте последнюю часть, например `0.4.0 → 0.4.1`.
2. Запустите `cargo check --manifest-path studio/Cargo.toml` из корня
   и сохраните обновлённый `studio/Cargo.lock`.
3. Обновите текущую версию и добавьте запись ниже. Соберите пакет по
   [studio/BUILD.md](studio/BUILD.md). Номер в имени пакета и интерфейсе
   должен совпадать с `Cargo.toml`.

## 0.4.0

- «Обзор» показывает проект, локальную сборку и результат сверки Flash по SWD.
- Для проекта можно выбрать «Только SWD» или инструменты прошивки primGPT.
- В «SWD-отладке» появились дерево файлов, вкладки исходников, поиск функций
  и переход к месту останова.
- Флажок в «SWD-отладке» управляет автоматическим открытием Cursor при
  остановке. Для новых настроек он выключен.
